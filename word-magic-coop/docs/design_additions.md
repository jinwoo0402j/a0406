# 기획 추가 요구사항

v0.3 이후 사용자가 대화로 확정한 요구사항입니다. 기획서 본문과 충돌하면 이 문서를 따릅니다.

## 2026-09-30 — 지속형 마법의 시전 종료

- 지속형 마법은 시전자가 **종료 버튼**을 눌러 직접 중단할 수 있어야 한다.
- 예: `<들기>` 사용 중 종료 버튼을 누르면 물체를 놓는다.
- 구체적인 키 배정은 추후 결정한다. (현재 구현: 우클릭 [임시])
- 이것은 **자신이 유지하는 마법을 끝내는 기능**이며, **친구가 건 마법에서 벗어나는 기능(R 해제)과는 별개**다.

## 2026-10-01 — 미정 사항 제안안 승인

v0.3 07장의 미정 사항에 대해 Claude가 제안하고 사용자가 승인한 안입니다. 플레이테스트 뒤 바뀔 수 있습니다.

| 미정 사항 | 정한 안 | 이유 |
| --- | --- | --- |
| 본인 + 들기 | 막음 | 혼자 높은 곳에 오르면 "친구가 들어 줘야 넘는" 협동 퍼즐이 깨진다 |
| 주변 + 들기 | 주변의 들 수 있는 것을 가벼운 것부터, 나눠 든 무게 합이 힘 안일 때까지 여러 개 | 무게 규칙을 그대로 쓰고 `<세게>`를 모을 이유가 생긴다 |
| 본인 + 파이어볼 | 발밑 폭발. 시전자는 피해 없이 (땅에 있을 때만) 튀어 오르고 둘레는 폭발을 맞는다 | 웃긴 장면과 이동 수단. 단차는 넘지 못하게 낮게 |
| 주변 + 파이어볼 | 사방으로 4발 | "실제로 맞은 대상에 적용" 규칙을 그대로 지키는 범위 공격 |
| 아군 디버프 | 2초 둔화 유지. 다시 맞으면 2초로 갱신(쌓이지 않음) | 한 친구를 계속 묶어 두는 방해 방지(v0.2 원칙) |
| 수식 상한 | 5중첩 유지 | 맵에 `<큰>`이 3개뿐이라 지금은 영향 없음 |
| 여러 명이 같이 들기 | 허용. 무게를 사람 수로 나누고, 물체는 드는 사람들 목표 지점의 가운데로 | 협동의 핵심. 혼자 못 드는 것을 둘이 든다 |
| 전투 | 지금은 넣지 않음 | 기획서: 단어를 모으고 익숙해진 뒤 등장 |
| 월드 | 테스트 방 유지 | 확장은 플레이테스트 뒤 |
| 시전 종료 키 | 우클릭 유지 | 시전·종료가 한 손 마우스에 대칭 |
| 새 효과 단어 | `<당기기>`: 조준(내 앞까지 끌어옴, 지형이면 내가 끌려감)·주변(모으기) | 기획서 v0.2 08장 "새 작용 1종의 여러 용도 확인". 밀치기의 반대라 물리를 재사용 |

구현하면서 더한 것:
- **붙잡기**: 혼자 못 드는 물체도 조준 모드로 붙잡을 수 있다(뜨지 않음). 그래야 친구가 합류할 수 있다.
- 2인 플레이에서도 같이 들 수 있도록 발견 구역(무거운 상자 옆)에 `<들기>` 1개를 더 놓았다.
- 서로·고리로 들기 금지: 나를 직접·간접으로 들고 있는 사람은 들 수 없다(끝없이 올라가는 것 방지).

## 2026-10-01 — 가방을 마인크래프트 인벤토리 규칙·형식으로

| 마인크래프트 | 반영 |
| --- | --- |
| 가방 27칸 + 핫바 9칸, 위쪽에 갑옷·제작 칸 | 가방 27칸 + 핫바 9칸, 위쪽에 **주문 칸**([손] + [수식 5칸] → [결과]) |
| 손 = 고른 핫바 칸(1~9·휠) | 손 = 고른 핫바 칸의 효과 단어 |
| 갑옷 칸: 한 칸에 하나, 맞는 종류만 | 수식 칸: 한 칸에 하나, 수식 단어만 |
| 좌클릭 집기/놓기/합치기/바꾸기, 우클릭 반 집기/하나 놓기, Shift 빠른 이동 | 같음 |
| 칸 위에서 숫자키 = 핫바와 바꾸기, Q/Ctrl+Q 던지기, 창 밖 클릭 던지기 | 같음 |
| 주우면 같은 묶음 → 핫바 → 가방 순서, 장비는 자동으로 안 입음 | 같음(수식은 주워도 자동으로 안 붙음) |
| 아이템 개수는 오른쪽 아래 숫자, 마우스 올리면 이름 | 같음 |

다른 점: 창을 닫을 때 커서에 든 단어는 던지지 않고 가방으로 돌려놓는다. (끌어서 나눠 놓기·두 번 클릭 모으기는 2026-10-01에 추가)

## 2026-10-01 — 글자 대신 기호, 1인칭 손(PEAK 참고)

사용자 요청: "지금 텍스트들 대부분이 기호로 표기할 수 있잖아? 기획해서 그렇게 좀 해줘." / "이 게임 1인칭인게 좋지 않을까? 손만 보이는 1인칭? PEAK 연구해서 참고해봐."

### 글자 → 기호 기준
| 바꾼 것 | 기호 |
| --- | --- |
| 사람 이름("플레이어 A", "나") | 자리 색 동그라미 + 글자(A·B…) |
| 조작 안내("F 대상 모드" 등) | 키 모양 + 그림(F + 과녁, Q + 던지기 화살표 …) |
| 대상 모드(조준·본인·주변) | 과녁 · 사람 · 점선 원 3개 중 켜진 것 |
| 효과·수식 | 단어 앞에 그림(밀치기 ⇒, 당기기 ⇐, 들기 ↑, 파이어볼 불꽃, 큰 ⌜⌟, 세게 번개) |
| 미리보기·거절 이유 | 그림 + 대상 동그라미(예: 들기 → 무거운 상자, 무게 → 세게/친구) |
| 상태(들림·느려짐·보호) | 아래 가운데 막대 옆 작은 기호 + 남은 초 |
| 처음 해보기 안내 | 단계 점 5개 + 그림 순서(예: 좌클릭 → 밀치기 → 친구/짐) |
| 로그·알림 | 사람 동그라미 + 단어 표 + 화살표(예: A → 들기 → B) |
| 도착 목표 | 깃발 + 선물 상자(짐) + 사람 동그라미(도착하면 초록 테두리) |

글자로 둔 것: 단어 이름(게임의 내용), 물건 이름(돌·상자), 로비 화면, 판 요약(복사해서 전하는 기록), "앗!"·"짜잔!"·"클릭!" 같은 짧은 감탄.

### 1인칭(PEAK 참고)
조사: PEAK는 1인칭 협동 등반 게임으로, 화면 아래에 두 손만 보이고 화면 표시는 아래 가운데 체력·기력 막대 + 칸 몇 개뿐이다.

| PEAK | 반영 |
| --- | --- |
| 1인칭, 두 손만 보임 | 기본 1인칭. 내 동물 주민의 소매 + 통통한 발바닥 손(손바닥에 분홍 젤리), 내 몸은 숨김 |
| 손이 행동을 보여 줌(잡기·들기) | 시전 = 오른손 내밀기, 들기 유지 = 두 손 들어 손바닥 앞으로(무거우면 버둥), 던지기 = 휙, 줍기 = 왼손 쥐기, 걸으면 흔들림, 시점 돌리면 살짝 늦게 따라옴 |
| 든 물건이 손에 보임 | 오른손 위에 지금 든 효과 단어(구슬 + 이름표) |
| 화면 표시 최소, 아래 가운데 막대 | 재사용 대기 막대 + 상태 기호를 핫바 바로 위에 |
| — | V로 3인칭(어깨 너머)도 남김: 친구와 같이 들 때 내 몸 위치를 보고 싶을 수 있음 |

손은 본 장면 위에 따로 그린다(깊이만 지우고) → 벽에 붙어도 손이 파묻히지 않는다. 조준선은 눈 위치에서 나가며, 시전자 자신은 판정에서 빠진다(판정 규칙은 그대로).

## 2026-10-01 — 사용자 부재 중 작업(판단 없이 해야 할 것)

1. **내 캐릭터 반응 지연 줄이기**: 1인칭에서는 키를 누른 뒤 화면이 늦게 움직이는 게 더 잘 느껴진다.
   - 서버 최신 상태에서 시작해, 왕복 지연 동안 아직 서버에 닿지 않은 내 입력과 그 뒤 흐른 시간을 서버와 같은 이동 규칙(server/physics.js)으로 미리 움직여 그린다(표시 전용, 판정은 호스트).
   - 왕복 지연은 1초마다 `rtt` → `pong`으로 잰다.
   - 새 스냅숏으로 예측이 바뀌면 그 차이는 0.1초쯤에 걸쳐 부드럽게 흡수한다. 1.5m 넘게 어긋나면(낙하 복구 등) 바로 맞춘다.
   - 친구에게 들려 있는 동안에는 예측하지 않는다. 내가 든 물체는 내 몸이 앞당겨진 만큼 같이 앞당긴다.
   - 미리보기 판정은 호스트와 같은 시점(보간 위치)으로 한다. 호스트가 그 시점으로 되돌려 판정하기 때문이다.
   - 측정(헤드리스): 키 → 5cm 움직임 154ms → 64~90ms. 걷는 동안 서버와의 차이 0.04m 이하.
2. **가방 남은 마인크래프트 규칙**: 단어를 든 채 끌기(좌: 고르게 나눔, 우: 하나씩), 두 번 클릭 모으기(수식만, 수식 칸은 그대로).
3. **2차 점검**
   - 지연을 넣은 멀티 측정(`scripts/lag-check.mjs`, 한 방향 60ms): 예측을 켜면 키 → 움직임 249ms → 72ms, 키를 뗀 뒤 미끄러짐 1.1m → 0.26m(원래 감속 거리 수준), 뒤로 튐 없음.
   - 이동 키는 누르거나 떼는 순간 바로 보낸다(다음 프레임을 기다리지 않음).
   - 느려짐 수정: 기호(SVG)가 많아진 HUD가 매 프레임 다시 그려지던 것을 고쳤다. 둥실 애니메이션은 translate로 바꾸고, 값이 바뀔 때만 DOM에 쓴다. 헤드리스 fps 7 → 9.7~14(오늘 작업 전 9~9.3).
   - 코드 검토로 고친 것:

     - 무거워 못 든 물체는 앞당기지 않고, 연쇄로 든 물체(친구가 든 상자)는 함께 앞당긴다.

     - 창 전환 등으로 놓친 끌기 상태를 버린다.

## 2026-10-02 — 세계의 성질을 단어로 얻고, 그 단어로 다시 세계를 바꾼다

사용자가 정한 방향(원문 요지):
- 단어 조합의 결과는 **놓은 순서가 아니라 종류와 개수**로 정한다.
- 조합·시전은 직관적으로 하고, 다양성은 **단어 종류와 상호작용**으로 만든다.
- **단어의 뜻이 곧 마법의 효과**라는 원칙은 그대로 둔다.
- 단어는 상자 보상뿐 아니라 **세계의 사물·환경에 손을 대는 행동**으로도 얻는다. 예: 커다란 바위를 마법으로 조금씩 부수면 그 성질인 `<큰>`이 떨어진다.
- `<물>` + `<불>` → `<수증기>`처럼 **단어끼리 반응해 새 단어**가 생긴다.
- 추운 곳에 물을 쏘면 얼음이 생기는 것처럼 **마법과 환경이 서로 영향을 준다**.
- 생긴 현상을 단어로 거두는 방법은 나중에 정한다. 다만 **왜 그 단어를 얻는지 납득**할 수 있어야 한다.
- 친구들은 단어를 주고받거나 마법을 함께 쓰며 새 반응과 쓰임새를 찾는다.
- 핵심: **세계의 성질을 단어로 얻고, 그 단어로 다시 세계를 바꾸는 마법사 경험.**

### 이번에 구현한 것(첫 단계) [제안안·임시 수치]

**단어를 얻는 규칙: 동사가 사물의 성질을 떼어 낸다.** 얻는 이유를 행동에서 바로 알 수 있게 동사 두 가지로 묶었다.

| 행동 | 사물 | 나오는 단어 | 왜 그 단어인가 |
| --- | --- | --- | --- |
| 때려서 부수기(`<밀치기>`·`<당기기>`·`<파이어볼>` 폭발) | 커다란 바위(출발 구역 왼쪽) | `<큰>` × 3 | 맞을 때마다 깎이고, 3단계로 작아질 때마다 "큼"이 하나씩 떨어진다. 다 부서지면 바위는 사라진다 |
| `<당기기>`로 뽑아내기 | 모닥불(출발 구역 오른쪽) | `<불>` | 불을 끌어냈으니 모닥불은 꺼진다 |
| `<당기기>`로 뽑아내기 | 샘(발견 구역 왼쪽 뒤) | `<물>` | 물을 길어 냈으니 샘이 빈다 |

- 떨어진 단어는 시전자 쪽으로 튀어 와서 몸에 닿으면 주워진다(기존 자동 줍기).
- 꺼진 모닥불·빈 샘은 20초 뒤 다시 차오른다. `<불>`을 쏘면 모닥불이 바로 다시 붙고, `<물>`을 쏘면 샘이 바로 찬다.
- 모닥불·샘은 한 판에 단어를 3개까지만 내준다(단어가 끝없이 늘지 않게).
- 미리보기: `<당기기>`로 모닥불을 겨누면 "모닥불 → `<불>`"처럼 무엇이 나올지 미리 보인다.

**새 단어(뜻 = 효과)**

| 단어 | 시전 | 대상 모드 | 효과 |
| --- | --- | --- | --- |
| `<물>` | 투사체 | 조준·본인·주변(4발) | 맞은 곳에 물이 튄다: 살짝 밀고, 친구의 그을림을 씻고, 모닥불을 끄고, 빈 샘을 채운다. **추운 곳에 닿으면 얼음 덩이**가 생긴다. 본인 모드는 내게 끼얹어 그을림을 씻는다 |
| `<불>` | 즉시 | 조준·주변 | 데운다: 허수아비 피해, 친구 그을림, **얼음 녹이기**, 꺼진 모닥불 붙이기 |
| `<수증기>` | 즉시 | 조준·주변 | 뜨거운 김이 솟아 대상을 위로 약 1.2m 띄운다. 본인 모드는 막았다(혼자 높은 곳에 오르면 협동이 깨진다는 기존 결정과 같음) |

수식은 그대로 늘어난다: `<큰>`은 물방울 크기·범위, `<세게>`는 미는 힘·피해·띄우는 높이.

**환경**
- 도착 단차 아래 왼쪽에 **눈밭(추운 곳)**을 두었다. 여기에 닿은 `<물>`은 얼음 덩이가 된다(동시에 3개까지, 더 만들면 가장 오래된 것이 녹는다).
- 얼음은 들고 밀 수 있는 사물이다. 눈밭 밖으로 옮기면 12초 뒤 녹고, `<불>`이나 파이어볼에 닿으면 바로 녹아 김이 오른다.
- 바위·모닥불·샘은 제자리에 박혀 있어 밀리거나 들리지 않는다.

**단어끼리의 반응(섞기)** — 마인크래프트의 2×2 제작 칸처럼
- 가방(E)의 주문 칸 아래에 **섞는 칸 4개 + 결과 칸**을 두었다. 아무 단어나 한 칸에 하나씩 넣는다.
- 결과는 **넣은 단어의 종류와 개수만으로** 정해진다(어느 칸에 어떤 순서로 넣었는지는 보지 않는다). 맞는 반응이 있으면 결과 칸이 반짝이고, 누르면 재료 단어들이 새 단어 하나가 된다.
- 지금 있는 반응: `<물>` + `<불>` → `<수증기>`. 가방을 닫으면 섞는 칸의 단어는 가방으로 돌아간다.
- 주문 칸도 같은 원칙이다: 수식은 칸 순서와 상관없이 단어별 개수로만 센다(원래도 그랬고, 테스트로 고정했다).

### 다음에 정할 것
- 생긴 현상(얼음, 김, 꺼진 불의 재 등)을 단어로 거두는 방법. 후보: 얼음을 부수면 `<차가운>`, 김에 `<당기기>`를 쓰면 `<수증기>`.
- 반응 늘리기(예: `<물>` + `<큰>`?). 수식이 들어간 반응을 허용할지.
- 바위처럼 부수면 성질이 떨어지는 사물 더 놓기(예: 무거운 상자 → `<세게>`?), 처음 놓인 단어를 줄이고 세계에서 얻는 쪽으로 옮길지.
- 단어를 얻는 퍼즐: 눈밭 얼음을 디딤돌로 쓰는 길, 모닥불을 지켜야 하는 상황 등.
