# 기획 추가 요구사항

v0.3 이후 사용자가 대화로 확정한 요구사항입니다. 기획서 본문과 충돌하면 이 문서를 따릅니다.

## 2026-09-30 — 지속형 마법의 시전 종료

- 지속형 마법은 시전자가 **종료 버튼**을 눌러 직접 중단할 수 있어야 한다.
- 예: `<들기>` 사용 중 종료 버튼을 누르면 물체를 놓는다.
- 구체적인 키 배정은 추후 결정한다. (현재 구현: 우클릭 [임시])
- 이것은 **자신이 유지하는 마법을 끝내는 기능**이며, **친구가 건 마법에서 벗어나는 기능(R 해제)과는 별개**다.

## 2026-10-01 — 미정 사항 제안안 승인

v0.3 07장의 미정 사항에 대해 Claude가 제안하고 사용자가 승인한 안입니다. 플레이테스트 뒤 바뀔 수 있습니다.

| 미정 사항 | 정한 안 | 이유 |
| --- | --- | --- |
| 본인 + 들기 | 막음 | 혼자 높은 곳에 오르면 "친구가 들어 줘야 넘는" 협동 퍼즐이 깨진다 |
| 주변 + 들기 | 주변의 들 수 있는 것을 가벼운 것부터, 나눠 든 무게 합이 힘 안일 때까지 여러 개 | 무게 규칙을 그대로 쓰고 `<세게>`를 모을 이유가 생긴다 |
| 본인 + 파이어볼 | 발밑 폭발. 시전자는 피해 없이 (땅에 있을 때만) 튀어 오르고 둘레는 폭발을 맞는다 | 웃긴 장면과 이동 수단. 단차는 넘지 못하게 낮게 |
| 주변 + 파이어볼 | 사방으로 4발 | "실제로 맞은 대상에 적용" 규칙을 그대로 지키는 범위 공격 |
| 아군 디버프 | 2초 둔화 유지. 다시 맞으면 2초로 갱신(쌓이지 않음) | 한 친구를 계속 묶어 두는 방해 방지(v0.2 원칙) |
| 수식 상한 | 5중첩 유지 | 맵에 `<큰>`이 3개뿐이라 지금은 영향 없음 |
| 여러 명이 같이 들기 | 허용. 무게를 사람 수로 나누고, 물체는 드는 사람들 목표 지점의 가운데로 | 협동의 핵심. 혼자 못 드는 것을 둘이 든다 |
| 전투 | 지금은 넣지 않음 | 기획서: 단어를 모으고 익숙해진 뒤 등장 |
| 월드 | 테스트 방 유지 | 확장은 플레이테스트 뒤 |
| 시전 종료 키 | 우클릭 유지 | 시전·종료가 한 손 마우스에 대칭 |
| 새 효과 단어 | `<당기기>`: 조준(내 앞까지 끌어옴, 지형이면 내가 끌려감)·주변(모으기) | 기획서 v0.2 08장 "새 작용 1종의 여러 용도 확인". 밀치기의 반대라 물리를 재사용 |

구현하면서 더한 것:
- **붙잡기**: 혼자 못 드는 물체도 조준 모드로 붙잡을 수 있다(뜨지 않음). 그래야 친구가 합류할 수 있다.
- 2인 플레이에서도 같이 들 수 있도록 발견 구역(무거운 상자 옆)에 `<들기>` 1개를 더 놓았다.
- 서로·고리로 들기 금지: 나를 직접·간접으로 들고 있는 사람은 들 수 없다(끝없이 올라가는 것 방지).
