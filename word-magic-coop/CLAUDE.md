# 작업 규칙 (word-magic-coop)

## 테스트
- 바꿀 때마다: `npm test`(단위 테스트).
- 배포 전 한 번: `node scripts/e2e.mjs`(호스트 브라우저 E2E).
- **멀티(P2P) 테스트 `node scripts/e2e-p2p.mjs`는 매번 돌리지 않는다.** 네트워크 코드(p2p.js·host.js·server/index.js)를 바꿨거나, 다른 테스트가 틀렸거나, 사용자가 문제를 말했을 때만 돌린다. (사용자 요청: "앞으로 매번 멀티 테스트 하지마, 틀릴 때만 하면 되니깐")

## 사용자에게 답할 때
- 한국어, 어려운 말 없이 **딱 세 줄 요약** + TODO 목록.
- 웹 검색을 썼으면 출처 링크를 붙인다.
